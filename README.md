# Artificially Triggered Nature-based Sand Dunes — Agios Georgios, Naxos

A bilingual (English / Ελληνικά) on-site visitor guide for a University of Athens
field experiment in nature-based coastal protection: a 5-metre porous timber fence
that triggers wind-driven sand-dune formation at Agios Georgios beach (Airport
Lagoon), western Naxos.

**Live site:** https://uoa-gr.github.io/exp-dunes-naxos/

A single self-contained `index.html` (no build step). Photographs in `images/`.
